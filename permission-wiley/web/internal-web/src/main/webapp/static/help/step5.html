STEP 5: ADDING ASSETS

5a. Explanation of Project Landing Page

Once you reach the main project landing page, there are four main information sections.

Section 1: This box displays information about the title you are working on. This box allows you to mark that the project has No Permissions Required, Permissions Complete, and Bookmarked.
Note: Always add you assets first.
Section 2: This box displays the number of assets and their status.
Section 3: This box displays the project history, when and who entered information.
Section 4: This box is where assets are added.

5b. Adding Assets, Section 4

After you set the minimum requirements and add components, you can begin adding assets. To add an asset, click the “Click here to add asset” line in section 4.

After clicking add an asset, the fields will open. Enter in the information of the asset you wish to add. Some fields require you to type in the information and others include a drop-down menu.

To save the information you entered, simply deselect the box. The information you added will be saved automatically.

To add another asset, follow the same steps. A new “Click here to add asset” line will automatically appear after every entered asset. To edit an asset, simply click on that line.
