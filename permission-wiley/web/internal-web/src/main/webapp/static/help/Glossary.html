PERMISSION STATUS GLOSSARY

No source = no ownership information
Unrequested = no permissions request has been created
Form sent = waiting for reply from source
Amendment needed = a limitation of liability amendment needs to be created
Amendment sent = waiting for signed amendment from source
Unpaid = this asset is waiting for a payment request
Contract insufficient = the contract terms do not meet the set up requirements for this project
Out of compliance = the contract has expired or the print run has been exceeded
Granted unlimited = there are no limitations to the use of this asset in this project
Granted limited = the asset is usable with some conditions
Cancelled = this asset will not be used in this project
