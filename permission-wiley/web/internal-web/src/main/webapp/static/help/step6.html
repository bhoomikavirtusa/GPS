STEP 6: ADDING SOURCES

After adding in the basic details about an asset, you must add the source, the provider of the asset. To enter a source, click the link “Enter details” under Sources in section 4. After clicking “Enter details,” an enter details wizard will appear. The wizard will provide you with different types of sources. Select the appropriate source and click Next.

The next dialogue box will ask for the Source Name. As you enter in the name of the source, options will appear. These options are sources that have already been entered into Core. You can also choose a source from the Select Previous and Select favorite drop down menus. After you find the appropriate source, select it, and click Next.

Note: How to create a new source will be discussed later in this tutorial.

The next dialogue box gives you the opportunity to enter in a source ref #, a credit line, mark the asset as public domain or fair use, and special instructions. If you do not have any of this information, simply click next. Also, you can add the source to your favorites list by selecting the Favorite source button. Your favorites will then appear in the drop down menu shown in the previous image. Note: This information can be edited later.

Quick Tip: If an asterisk appears next to an item, it is a required field.

The next dialogue box asks for more details concerning the asset. Enter in all the required information, as well as any inessential information you know, such as the caption. After entering in the information, click Finish.

Once you have entered in a source for an asset, the source name will appear under Sources. If you need to edit/add a source, click "Change Source".

A dialogue box will appear and give you the option to add a new additional source, reselect and edit the current source, or cancel the entire operation. If you chose to add or reselect, the following wizard will be the same used when adding the first source.
