STEP 4: SETTING REQUIREMENTS AND COMPONENTS

4a. Setting Minimum Requirements

Once you are on the project landing page, the first thing you will need to do is set the minimum permissions requirements.

The View/Edit Minimum Permissions Requirements wizard will appear if the project you chose has never had any information entered. The preset conditions that appear in the dialogue box are the default conditions. If these conditions meet the project requirements press Continue. If they do not, press Edit.

Note: Every asset that you enter into the system must meet these requirements.

4b. Editing Requirements

If you chose to edit the minimum requirements, a wizard will appear, and the dialogue box will show each requirement and its components. These requirements can be edited by selecting or deselecting the boxes. A requirement will appear differently based on the type of selection. If a requirement is checked but has something excluded, then it will appear unchecked and highlighted in blue. For example, say "All languages except European" are selected, then the All will appear unchecked and highlighted because not everything is included. If everything is included, for example, "All Nordic Languages," then it will appear as a checked box. If nothing is included, for example, "European languages," then the box remains unchecked.

Quick Reference: Everything selected = checked box; Nothing selected = unchecked box; Some things selected = unchecked, highlighted blue box.

After you sent your requirements and press save, the minimum requirements wizard will no longer appear when returning to the projects landing page.

4c. Creating Components

Once you save your minimum requirements, the Create Components wizard will appear.

Components are organized units which compose a title. These are usually chapters, prefaces, introductions, prologues, etc. The components you will want to add are the components that contain permissionable items, or assets. To add a component, simply click the select box, which will open into a drop box with multiple options, and select the component you want to create. To add chapters, select the Chapters box and enter in the chapter range. Once you have chosen the components, click the Add button.

Note: You can also edit or add more components later.

Quick Tip: Adding all the chapters available (entering in the entire range) is suggested.
