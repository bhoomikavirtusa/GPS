create a file in GPS/bin named setenv.sh and create these commands inside it.

export JAVA_HOME=/usr/java/java-21-openjdk-21.0.9.0.10-1.el8.x86_64
export JRE_HOME="$JAVA_HOME"
export PATH="$JAVA_HOME/bin:$PATH"
export JAVA_OPTS="-server -Xms1024m -Xmx2048m --add-opens=java.base/java.lang=ALL-UNNAMED --add-opens=java.base/java.util=ALL-UNNAMED --add-opens=java.base/java.lang.reflect=ALL-UNNAMED --add-opens=java.base/java.text=ALL-UNNAMED --add-opens=java.base/java.io=ALL-UNNAMED --add-opens=java.desktop/java.awt.font=ALL-UNNAMED --patch-module java.base=/opt/software/GPS/lib/compat/compiler-shim.jar"

-----------------

create a folder named compat inside lib folder (/opt/software/GPS/lib/)
paste that jar in that folder (jar present inside /jdk21-compat/java-lang-compiler-shim/compiler-shim.jar)

---------------------
once done stop and start Catalina.
